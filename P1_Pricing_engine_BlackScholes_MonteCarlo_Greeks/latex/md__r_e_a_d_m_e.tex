Moteur de pricing d\textquotesingle{}options vanilles européennes en C++17, comparant un pricer analytique (Black-\/\+Scholes-\/\+Merton fermé) à un pricer par simulation Monte Carlo parallélisé, avec calcul complet des Greeks (Delta, Gamma, Vega, Theta, Rho) sur les deux moteurs.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Pourquoi ce projet}{Pourquoi ce projet}}\label{md__r_e_a_d_m_e_autotoc_md1}
Il valide trois choses en une fois :


\begin{DoxyEnumerate}
\item Le prix Monte Carlo {\bfseries{converge}} vers le prix fermé de Black-\/\+Scholes (validation croisée).
\item Le moteur est {\bfseries{optimisé}} : antithetic variates + Common Random Numbers pour les Greeks + parallélisation Open\+MP.
\item Le code est {\bfseries{réutilisable}} : {\ttfamily Monte\+Carlo::\+price()} fonctionne pour n\textquotesingle{}importe quel payoff vanille sans formule fermée, peut servir de base pour de futurs projets sur des options exotiques.
\end{DoxyEnumerate}\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Modèle}{Modèle}}\label{md__r_e_a_d_m_e_autotoc_md2}
Sous la mesure risque-\/neutre, le sous-\/jacent suit un mouvement brownien géométrique (GBM) :


\begin{DoxyCode}{0}

Le prix terminal se simule directement (sans discrétisation intermédiaire, car GBM a une solution exacte) :

\begin{DoxyItemize}
\item GBM à volatilité constante : pas de smile de volatilité (voir pour un projet de calibration SVI/\+\+SABR pour une extension réaliste).
\item Options européennes uniquement, le projet suivant de la roadmap (EDP/\+différences finies) traite l\textquotesingle{}exercice anticipé américain.
\item Les Greeks Monte Carlo sont estimés par différences finies : biaisés à l\textquotesingle{}ordre O(h²) près, ce qui est acceptable ici mais mériterait des pathwise/\+likelihood-\/ratio estimators dans une version plus avancée. 
\end{DoxyItemize}
